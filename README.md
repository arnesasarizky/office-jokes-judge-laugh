## The joke

> One reply-all 'thanks' to 4,000 colleagues later, the thread is nine days old and has its own onboarding doc.

## How to run

Run the program with Node:

```sh
node main.ts
```

It creates `/output` if needed and writes the joke exactly — no trailing newline — to `/output/entry.txt`. The program also guards the 199-character limit, so the output always stays inside the entry gate.
